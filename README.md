## How to Host this Website Free on GitHub Pages

### Step-by-Step Guide (Very Easy)

#### 1. Create a GitHub Account
- Go to [https://github.com](https://github.com) and sign up (if you don’t have an account).

#### 2. Create a New Repository
1. Click the **+** icon (top right) → **New repository**
2. Repository name: `Gurukul`
3. Make it **Public**
4. **Do NOT** check “Add a README file”
5. Click **Create repository**

#### 3. Upload the Website Files
1. On the new repository page, click **uploading an existing file**
2. Drag and drop these two files:
   - `index.html`
   - `README.md`
3. Scroll down and click **Commit changes**

#### 4. Enable GitHub Pages
1. Go to your repository → Click **Settings** (top menu)
2. On the left sidebar, click **Pages**
3. Under **Source**, select:
   - Branch: `main`
   - Folder: `/ (root)`
4. Click **Save**

#### 5. Your Website is Live!
- Wait 1–2 minutes
- Your website will be available at:

```
https://YOUR-USERNAME.github.io/Gurukul/
```

Example:  
If your GitHub username is `derozioacademy`, the link will be:  
`https://derozioacademy.github.io/Gurukul/`
